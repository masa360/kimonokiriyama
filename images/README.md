# 画像フォルダ

予約ページで使う写真を置く。
**コード側（`index.html`）がファイル名を直接見ている。名前を変えると表示されない。**

## どの写真が、どこに出るか

| 出る場所 | ファイル | 見え方 |
| :-- | :-- | :-- |
| 和装体験の「こんな写真が撮れます」ボタン | `taiken.jpg`（前姿）・`kimono-11.jpg`（横姿）・`kimono-12.jpg`（後ろ姿） | 前へ／次へで送れる |
| 和装本格着付けの同ボタン | `honkaku.jpg`（前姿）・`kimono-13.jpg`（横姿）・`kimono-14.jpg`（後ろ姿）・`kimono-15.jpg`（男性） | 同上 |
| 開いたときの導入演出 | `intro-1.jpg`・`intro-2.jpg`・`honkaku.jpg`・`kimono-13.jpg`・`kimono-15.jpg` | 文字のあと、写真が順にフェードで出る |
| 打掛ギャラリー（「お衣装（打掛）を見る」） | `kimono-1.jpg` 〜 `kimono-15.jpg`（現在**15枚**） | 前へ／次へで送れる |

- **`honkaku.jpg`・`kimono-13.jpg`・`kimono-15.jpg` は複数の場所で使っている。** 差し替えると、すべてに効く
- 写真の対応は `index.html` の `MENU_PHOTOS`（プラン）・`INTRO_PHOTOS`（導入）・`GALLERY_PHOTOS`（ギャラリー）
- 増やすときは、**ファイルを置き、`index.html` のその配列にも1行足す**（例：ギャラリーなら `kimono-16.jpg`）

## 揃っていなくてよい

- プラン写真・ギャラリーは、**実在する分だけ**を自動で拾う。欠番があっても詰めて表示する
- あるプランの写真が**1枚も無ければ、そのプランのボタンごと出ない**
  （押しても何も出ないボタンは、お客様には不具合に見えるため）
- 導入演出は、**1枚目（`intro-1.jpg`）が無いと演出ごと出ない**

> ⚠️ **衣装の「指定」はしない。**
> システムは在庫を知らないため、同じ日に2組が同じ衣装を選べてしまう。
> ギャラリーは雰囲気を見せるだけで、選ぶのは当日その場。
> 画面には「当日お選びいただけます・写真は一例です」と出る。

> 導入演出は、1枚あたり約1.1秒で切り替わる。**枚数を増やすと、そのぶん演出が長くなる**
> （5枚で、写真の部分が約5.5秒）。タップ・スクロールでいつでも飛ばせるが、増やしすぎないこと。

## 写真の条件

| 項目 | 目安 |
| :-- | :-- |
| 形式 | JPG |
| 幅 | **1200px 程度**。これより大きいと読み込みが遅い |
| 容量 | **300KB以下**。スマホで見る前提 |
| 向き | 縦でも横でもよい（画面に合わせて収まる） |

> リポジトリに画像を入れると、GitHub Pages がそのまま配信する。
> 重い画像を置くと、その分ページの表示が遅くなる。

## 体験プランの写真で気をつけたいこと

差額は27,500円ある。**その差が写真で分かること**が大事。

| プラン | 見せたい状態 |
| :-- | :-- |
| 和装体験 | **服の上から羽織った状態**。ヘアセットなしと分かるもの |
| 和装本格着付け | しっかり着た全身。ヘアセットあり |

⚠️ 体験プランの写真が本格着付けに見えてしまうと、
当日「話が違う」になる。**ヘアセットの有無が見分けられる**ものを選ぶこと。

⚠️ 人物が写る写真は、**掲載の許可を得てから**置くこと。

## 大きい画像が届いたとき

スマホで見る前提なので、**300KBを超えたら縮める**。
重いと、見る前に離脱される。

```python
from PIL import Image
im = Image.open("元の画像.jpg")
r = min(1200 / im.width, 1200 / im.height, 1.0)   # 長辺1200pxに収める
im.resize((round(im.width * r), round(im.height * r)), Image.LANCZOS)   .save("taiken.jpg", "JPEG", quality=85, optimize=True, progressive=True)
```

実績：
- 2448×2581px / 1,636KB → 1138×1200px / 287KB
- 2432×3240px / 979KB → 901×1200px / 154KB（体験プラン写真）

いずれも表示サイズでは劣化が分からない。
