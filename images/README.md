# 画像フォルダ

予約ページのプランカードに出す写真を置く。

## ファイル名（この名前で置くこと）

コード側がこの名前を直接見ている。名前が違うと表示されない。

| ファイル名 | 内容 |
| :-- | :-- |
| `taiken-1.jpg` | 和装体験（22,000円）の1枚目。**カードに出る写真** |
| `taiken-2.jpg` | 和装体験の2枚目（任意） |
| `taiken-3.jpg` | 和装体験の3枚目（任意） |
| `honkaku-1.jpg` | 本格着付け（49,500円）の1枚目。**カードに出る写真** |
| `honkaku-2.jpg` | 本格着付けの2枚目（任意） |
| `honkaku-3.jpg` | 本格着付けの3枚目（任意） |

`-1` は必須。`-2` `-3` は無ければ無いで動く（タップ時の追加表示に使う）。

## 写真の条件

| 項目 | 目安 |
| :-- | :-- |
| 形式 | JPG（写真）。透過が要るならPNG |
| 幅 | **1200px 程度**。これより大きいと読み込みが遅い |
| 容量 | **1枚300KB以下**。スマホで見る前提 |
| 縦横比 | 横長（4:3 か 16:9）が収まりがよい |

> リポジトリに画像を入れると、GitHub Pages がそのまま配信する。
> 重い画像を置くと、その分ページの表示が遅くなる。
> スマホで見るお客様が大半なので、容量は必ず絞ること。

## 撮ってもらう内容

**2つのプランの差が写真で分かること**が最優先。
差額は27,500円あるので、それが伝わらないと当日「話が違う」になる。

| プラン | 欲しい絵 |
| :-- | :-- |
| 和装体験 | **服の上から羽織った状態**の全身。ヘアセットなしと分かるもの |
| 和装本格着付け | しっかり着た全身＋**ヘアセットの寄り** |

⚠️ 人物が写る写真は、**掲載の許可を得てから**置くこと。
